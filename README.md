## この無料版でできること

1. 官公需情報からWeb制作・リニューアル・運用保守案件を探す
2. 案件を一次判定して、追う案件と見送る案件を分ける
3. 発注機関の原文で参加条件・期限・仕様を確認する
4. 探索結果をCSVへ残し、次回の検索条件を改善する

案件への応募可否や参加資格を自動判定するものではありません。最終確認は必ず発注機関の公告・仕様書・要領等で行ってください。
