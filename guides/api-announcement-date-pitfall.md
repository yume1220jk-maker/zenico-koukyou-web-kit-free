# 無料検証例：APIの掲載日だけで「新着案件」と判断しない

ZENICOの公共Web関連公告の無料候補抽出で、APIから**2026年9月16日**という日付で返された「令和8年度大分市行動変容ウェブサイトの構築および運用保守業務委託」を、発注機関の[大分市の元公告PDF](https://www.city.oita.oita.jp/o258/machizukuri/kankyo/documents/01_koukokubun_r8webisitekochiku.pdf)と突合しました。

## 原文で確認できた事実

- 元公告の日付：**2026年7月24日**（元公告PDF・1ページ）
- 参加表明書の期限：**2026年8月7日**（元公告PDF・2ページ）
- 企画提案書の期限：**2026年8月24日 17:15**（元公告PDF・2ページ）
- 提案限度価格：**10,507,000円（税込）**（元公告PDF・1ページ）
- 参加資格例：同種業務の自治体受注実績、ISO/IEC 27001又はプライバシーマーク保持（元公告PDF・2ページ）。

**2026年9月24日の時点で参加表明と企画提案の期限はいずれも終了しています。** API上の単一の日付を元公告日・受付開始日と決めつければ、受付終了案件を顧客へ「新着」と誤配信するリスクがあります。

この差異が生じた理由やAPIの個別の項目定義はこの例だけでは確定できません。再掲載・検索インデックス更新などと断定せず、**各案件の発注機関原文の日付を優先**します。

無料の自動取得プログラムはこの発見を受け、少なくとも「APIに提出期限が無い案件」「API上で既に期限切れの案件」を候補一覧から除くようにしました。**残る候補も原文突合前であり、受付中とは表示しません。** 今後も原文の修正・取消・資格制限・締切区分を確認してから判断してください。
