# 官公需情報ポータルを5分で試す：Web制作案件の探索フィットチェック（2026-10-01確認）

Web制作会社が、官公庁・自治体のWeb制作／改修／運用保守案件を探索対象にするかを、まず無料で判断するための短い手順です。

## 1. 公式ポータルで検索する

中小企業庁の官公需情報ポータルサイトでは、検索キーワード、入札件名、機関名、地域を使って検索できます。複数項目を指定するとAND条件になります。

- 公式ポータル: https://www.kkj.go.jp/s/
- 公式ヘルプ: https://www.kkj.go.jp/s/?help=1

最初は以下のような語を1つずつ試します。

- ホームページ
- Webサイト
- CMS
- リニューアル
- 運用保守
- コンテンツ制作

## 2. 検索結果を「案件候補」として扱う

公式ポータル自身も、すべての入札情報の提供を保証しておらず、個別内容は各発注機関へ確認するよう案内しています。また、発注機関の公開からポータル登録まで時間差が生じる場合があります。

したがって検索結果だけで「受付中」「参加可能」と決めず、候補ごとに発注機関の最新版の公告・仕様書・要領を確認します。

## 3. 5分で続ける価値があるか判定する

次の3つのうち2つ以上が当てはまるなら、探索表を作って継続観測する価値があります。

- 自社の対応領域に近い案件が複数見つかる
- 原公告まで追えば参加条件・期限を確認できる
- 毎週同じ検索を繰り返す作業が発生しそう

0〜1個なら、いったん無料検索だけで止めても構いません。

## 4. 続ける場合の最小記録

最低限、次の列だけ残します。

`案件名 / 発注機関 / 原文URL / 公告日 / 参加期限 / 提出期限 / 対応領域 / 次に確認すること`

「検索結果を保存する」より、「次に何を確認するか」を残す方が再調査を減らせます。

## 公式情報で確認した注意点

2026-10-01時点で官公需情報ポータルの公開ページには、検索条件、RSS/APIの案内、情報網羅性の限界、原発注機関への確認が必要である旨が掲載されています。仕様や掲載状況は変更されるため、必ず公式ページを正としてください。
