# 無料サンプルから有料版で何が変わるか — 1案件の作業例

官公需Web案件探索スターターキットは、案件そのものを販売する商品ではありません。Web制作会社が公共Web案件の候補を見つけたあと、**候補発見 → 一次判定 → 原文確認 → 週次見直し**を同じ型で回すための編集可能な作業テンプレートです。

## 無料版で試せること

無料リポジトリの `sample/` では、縮小版CSVと原文確認チェックリストを確認できます。まず無料版で、自社の案件探索にこの整理方法が合うか試してください。

## 有料版を使う場合の1案件の流れ

例として「自治体ホームページ リニューアル」の候補を見つけた場合：

1. **探索キーワード集**で、表現揺れを含む次の検索候補を決める。
2. **案件一次判定CSV**へ候補を記録し、追う／見送る判断材料を揃える。
3. **原文確認チェックリスト**で、発注機関の公告・仕様書・要領から参加条件、期限、対象業務を確認する。
4. **週次レビューテンプレート**へ結果を戻し、次週に残す検索語や見送る条件を更新する。

つまり、980円で買うのは「落札情報」や「参加資格の自動判定」ではなく、毎回ゼロから表や確認項目を作らずに済むための4つの編集可能なテンプレートです。
